The grid comes back with every answer, so a bowler can see which numbers decided it. It shows counts and yes/no checks only: no date of birth, and for over/under no age group, so it still says nothing about who is over or under. Facts that broke a rule are marked red. Each bowler is one row; the facts wrap, so nothing scrolls sideways at any width.
