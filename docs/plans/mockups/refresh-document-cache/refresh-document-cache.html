1. Introduction

These rules govern all NEBA-sanctioned tournaments. Entry into any NEBA event constitutes acceptance of these rules by the bowler, and by any team or organization the bowler represents.

2. Eligibility

Any bowler holding a current USBC membership is eligible to compete, subject to the entry restrictions listed for each tournament class.
